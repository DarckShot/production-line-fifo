# Production Line FIFO

SPA-приложение на Angular для визуализации и управления FIFO-очередью продуктов на производственной линии.

## Функциональность

- отображение продуктов в виде FIFO-очереди;
- добавление нового продукта в конец очереди;
- изменение статуса продукта;
- удаление продукта;
- обработка следующего такта производственной линии;
- автоматическое удаление продукта, достигшего конца очереди;
- журнал последних 20 событий.

Каждый продукт содержит:

- ID;
- время поступления;
- статус:
  - `В очереди`;
  - `Проверен`;
  - `Отбракован`.

## Технологии

- Angular
- TypeScript
- HTML

## Запуск проекта

### Требования

Перед запуском необходимо установить:

- Node.js
- npm

### Установка зависимостей

```bash
npm install
```

### Запуск development-сервера

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:4200
```

## Сборка

Для создания production-сборки:

```bash
npm run build
```

Результат сборки будет находиться в директории `dist/`.
