# Production Line FIFO

SPA-приложение на Angular для визуализации и управления FIFO-очередью продуктов на производственной линии.

Проект разработан в рамках тестового задания на позицию **Frontend Middle**.

## Текущее состояние

Подготовлены типы продукта и события, компоненты очереди, карточки продукта, формы, управления линией и журнала, а также слой состояния на Angular Signals. Форма добавления проверяет пустой и повторяющийся ID, автоматически задаёт время поступления и статус «В очереди». В карточке продукта можно изменить статус и удалить продукт. Кнопка «Следующий такт» продвигает очередь к выходу и удаляет самый ранний продукт.

В следующих этапах планируется:

- просматривать журнал последних 20 событий.

Каждый продукт содержит:

- ID;
- время поступления;
- статус:
  - `В очереди`;
  - `Проверен`;
  - `Отбракован`.

## Требования

Для запуска проекта необходимы:

- Node.js `>= 22.22.3`
- npm

Проверить установленные версии:

```bash
node -v
npm -v
```

## Установка

Клонировать репозиторий:

```bash
git clone <repository-url>
```

Перейти в директорию проекта:

```bash
cd production-line-fifo
```

Установить зависимости:

```bash
npm install
```

## Запуск

Запустить development-сервер:

```bash
npm start
```

или:

```bash
ng serve
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:4200
```

При изменении исходного кода страница автоматически обновляется.

## Сборка

Для создания production-сборки:

```bash
npm run build
```

или:

```bash
ng build
```

Результат сборки будет сохранён в директории:

```text
dist/
```

## Тестирование

Для запуска unit-тестов:

npm test

или:

## Архитектура

Приложение построено с использованием компонентного подхода и типизации TypeScript.

Состояние производственной линии вынесено в `ProductionLineStore`. Компоненты разделены по ответственности: отображение очереди, карточка продукта, форма добавления, управление тактом и журнал событий. Добавление, изменение статуса, ручное удаление и такты подключены к интерфейсу; запись событий ещё не реализована.
