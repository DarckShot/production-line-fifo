# Production Line FIFO

SPA на Angular для визуализации FIFO-очереди продуктов на производственной линии. Экран показывает движение от датчика входа к датчику отбраковки, позволяет управлять продуктами и отслеживать события линии.

## Возможности

- Добавление продукта по уникальному ID. Время поступления и статус «В очереди» задаются автоматически; пустые и повторяющиеся ID отклоняются.
- Отображение продуктов в порядке движения от входа к выходу. В карточке видны ID, время поступления и один из статусов: «В очереди», «Проверен», «Отбракован».
- Изменение статуса и ручное удаление продукта без нарушения FIFO-порядка.
- Кнопка «Следующий такт»: продукты анимированно продвигаются к выходу, самый ранний покидает очередь. Для пользователей с настройкой уменьшения движения анимация сокращена.
- Журнал последних 20 событий: добавление, смена статуса, ручное удаление и удаление после такта. Новые события отображаются сверху.
- Автоматическое сохранение очереди и журнала в LocalStorage и восстановление после перезагрузки страницы. При отсутствии сохранённых данных приложение запускается с пустым состоянием.

## Технологии

Angular 22, TypeScript, Angular Signals и Signal Forms, CSS, Vitest. Приложение построено из отдельных компонентов; состояние очереди находится в `ProductionLineStore`.

## Требования

- Node.js `22.22.3+` в ветке 22, `24.15.0+` в ветке 24 или `26+`;
- npm (проект использует npm 10.9.8).

Проверить версии: `node --version` и `npm --version`.

## Установка и запуск

Из корня проекта установите зависимости:

```bash
npm ci
```

Запустите development-сервер:

```bash
npm start
```

Откройте `http://localhost:4200/`. При изменении исходного кода страница обновляется автоматически.

## Production-сборка

```bash
npm run build
```

Результат находится в `dist/production-line-fifo/`.

## Unit-тесты

Однократный запуск всех тестов:

```bash
npm test -- --watch=false
```

Тесты проверяют операции FIFO-очереди, журнал событий, восстановление состояния и основные действия интерфейса.
