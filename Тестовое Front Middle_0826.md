  
**Тестовое задание**  
**Для соискателей на должность Frontend Middle**

2026

Разработать SPA-приложение на **Angular (последняя стабильная версия)** для визуализации FIFO-очереди продуктов на производственной линии.

Очередь отображает движение продуктов от **датчика входа** до **датчика отбраковки**. Каждый продукт должен содержать:

* ID  
* Время поступления  
* Статус (В очереди / Проверен / Отбракован)

**Функциональность**

* Отобразить FIFO-очередь в виде последовательности элементов.  
* Реализовать форму добавления нового продукта в конец очереди.  
* Реализовать изменение статуса продукта.  
* Реализовать удаление продукта из очереди.  
* Добавить кнопку **«Следующий такт»**, при нажатии которой очередь смещается на одну позицию, а продукт в конце автоматически удаляется.  
* Отображать журнал последних 20 событий (добавление, изменение статуса, удаление).

**Требования к проекту**

* Использовать **Angular (последняя стабильная версия)** и **TypeScript**.  
* Использовать компонентный подход и типизацию.  
* Код должен быть структурированным, читаемым и легко поддерживаемым.  
* Предоставить README с инструкцией по запуску проекта.

**Будет плюсом**

* Анимация перемещения элементов очереди.  
* Сохранение состояния в LocalStorage.

**Что оценивается**

* Архитектура проекта.  
* Качество кода.  
* Работа с состоянием приложения.  
* Переиспользуемость компонентов.  
* UX/UI и аккуратность реализации.
